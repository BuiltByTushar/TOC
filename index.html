Q1 (a) The Palindromic-Prefix Language L
Marks: 4 CO: CO1 Bloom Level: BL3 PO: PO1 PI: 1.1.1
Let Σ = {a, b} be an alphabet. A palindrome is a word which reads the same left-to-right or right-to-left (abba, aba, aa are palindromes; ab, aabb are not). A palindrome is non-trivial if it has length at least 2. Let L be the set of all words that contain a non-trivial palindrome as a prefix — that is, L = {w ∈ (a+b)* : w = uv for some non-trivial palindrome u and some v ∈ (a+b)*}.

(i) Give an example of a word in L which is not a palindrome.
(ii) Give three examples of words not in L.
(iii) Suppose ax is a string which is not in L, for some x ∈ Σ*. What can you say about x?
(iv) Show that L is regular.
Formal Definition & Decomposition

By definition, a word $w$ belongs to $L$ if and only if there exist strings $u, v \in \Sigma^*$ such that:

$$w = u \cdot v, \quad \text{where } u = u^R \text{ (a palindrome)}, \quad |u| \ge 2, \quad \text{and } v \in (a+b)^*$$

The definition places no restriction whatsoever on the suffix $v$. Therefore, any word whose beginning forms a palindrome of length $\ge 2$, but whose overall structure is asymmetric, satisfies the condition.

Primary Witness: w = abbaa
  • Decomposition: Choose $u = \text{abba}$ and $v = \text{a}$. Here $w = u \cdot v = \text{abba} \cdot \text{a} = \text{abbaa}$.
  • Prefix check: $u = \text{abba}$, so $u^R = \text{abba}$. Since $u = u^R$ and $|u| = 4 \ge 2$, $u$ is a non-trivial palindrome. Thus, $w \in L$.
  • Total reversal check: $w^R = (\text{abbaa})^R = \text{aabba}$. Clearly, $\text{abbaa} \ne \text{aabba}$, proving $w$ is not a palindrome.
Secondary Minimal Example: w = aab

An even shorter witness is $w = \text{aab}$. Choosing $u = \text{aa}$ ($|u|=2$, $u=u^R$) and $v = \text{b}$, we have $w \in L$. But $w^R = \text{baa} \ne \text{aab}$, so $w$ is not a palindrome.

Final Answer

w = abbaa (or w = aab) belongs to $L$ because it possesses the non-trivial palindromic prefix "abba" (or "aa"), yet the overall string reads differently in reverse ($(\text{abbaa})^R = \text{aabba} \ne \text{abbaa}$).

A string $w \in \Sigma^*$ is not in $L$ ($w \in L^c$) if and only if no prefix of $w$ of length $\ge 2$ is a palindrome.

Structural Insight: For a string of length $\ge 2$ to avoid $L$, its first two letters must differ (preventing $aa$ or $bb$). If it begins with $ab$, every subsequent letter must be $b$, because inserting any $a$ creates a palindromic prefix of the form $ab^k a$!
Final Answer

Three valid words not in $L$ are: ab, abb, and abbb (in general, any word from $\{ab^k : k \ge 1\}$ or $\{ba^k : k \ge 1\}$, as well as the base words $\varepsilon, a, b$).

We are given that the string $s = a \cdot x \notin L$ for some string $x \in \Sigma^*$. We seek an exact, necessary, and sufficient characterization of $x$.

Fundamental Lemma: The Exact Complement of L

Let $w \in \Sigma^*$. We classify when $w \notin L$ by induction on the position of characters:

  1. Length 0 and 1: $|w| < 2 \implies w \in \{\varepsilon, a, b\}$. These strings have no prefixes of length $\ge 2$, so they vacuously fail to contain any non-trivial palindrome. Hence $\varepsilon, a, b \notin L$.
  2. First two symbols must be distinct: If $|w| \ge 2$ and $w_1 = w_2$, then the prefix $w_1 w_2 \in \{aa, bb\}$ is a palindrome of length 2. This would immediately place $w \in L$. Thus, any word avoiding $L$ must start with ab... or ba....
  3. Case 1: Word starts with "ab":
    • What can the third symbol $w_3$ be? If $w_3 = a$, the prefix is aba, which is a palindrome of length 3 ($aba = (aba)^R$). Contradiction! Hence $w_3$ must be $b$, giving prefix abb.
    • What can the $(k+2)$-th symbol be after $ab^k$? Suppose an 'a' appears at any subsequent index: $w = a b^k a \dots$ for some $k \ge 1$. Notice that $u = a b^k a$ is a palindrome because reading it backwards gives $a b^k a$ ($u^R = u$). This would force $w \in L$!
    • Therefore, once a string starts with ab, no 'a' can ever appear again. The string can only be followed by zero or more $b$'s. This generates the exact infinite family $\{a b^k : k \ge 1\}$.
  4. Case 2: Word starts with "ba": By exact symmetry, any reappearance of $b$ produces a palindromic prefix $b a^k b$, so only additional $a$'s are permitted: $\{b a^k : k \ge 1\}$.
$$L^c = \Sigma^* \setminus L = \{\varepsilon, a, b\} \cup \{a b^k : k \ge 1\} \cup \{b a^k : k \ge 1\}$$
Deducing x from s = a · x ∉ L

Since $s = a \cdot x \in L^c$, we inspect all members of $L^c$ that begin with the letter a:

  • Sub-case A: $s = a$ itself. Here, $a \cdot x = a \implies x = \varepsilon = b^0$.
  • Sub-case B: $s = a b^k$ for some $k \ge 1$. Here, $a \cdot x = a \cdot b^k \implies x = b^k$ where $k \ge 1$.
  • The family $b a^k$ begins with 'b', so it cannot equal $a \cdot x$.
Converse Proof (Verification of Sufficiency)

Suppose $x = b^k$ for any $k \ge 0$. Then $a \cdot x = a b^k$. The prefixes of $a b^k$ of length $\ge 2$ are $a b, a b^2, a b^3, \dots, a b^k$. None of these is a palindrome because the first symbol is $a$ and the last is $b$ ($a \ne b$). Thus $a b^k$ contains no non-trivial palindromic prefix, so $a b^k \notin L$ holds unconditionally for all $k \ge 0$.

Examiner Pitfall Warning: Many students carelessly answer this question with the general complement $x \in \{\varepsilon, a, b\} \cup ab^+ \cup ba^+$. That is incorrect because the question specifies that the string already starts with an 'a' ($s = ax$). The letter $a$ is prefixed to $x$, narrowing the condition on $x$ exclusively to $x \in b^*$.
Final Answer

x must consist entirely of zero or more b's — that is, $x \in b^*$ (or $x = b^k$ for some integer $k \ge 0$). Equivalently, $x$ cannot contain any occurrence of the symbol 'a'. The moment even a single 'a' is present in $x$ (say $x = b^i a \dots$), the string $ax$ gains a palindromic prefix $a b^i a$ and immediately enters $L$.

We prove regularity using two complementary, definitive methods: (1) constructing an exact Regular Expression, and (2) constructing a Deterministic Finite Automaton (DFA).

Method 1: By Regular Expression

From our characterization in part (iii), any non-trivial palindrome must start and end with the same letter. The minimal non-trivial palindromes are:

  • Length 2: aa and bb
  • Length ≥ 3: ab⁺a (i.e. $a b^k a$ for $k \ge 1$) and ba⁺b (i.e. $b a^k b$ for $k \ge 1$)

Any longer palindrome prefix will contain one of these minimal palindromes as an initial segment (or will itself be in this form). Once any of these minimal palindromes occurs as a prefix, the remainder of the word can be arbitrary ($(a+b)^*$). Therefore:

$$L = (aa + bb + ab^+a + ba^+b)(a + b)^*$$

Since $L$ is expressed using only union ($+$), concatenation, and Kleene star ($*$) over a finite alphabet, by Kleene's Theorem, $L$ is a regular language.

Method 2: By DFA State Construction

We construct a DFA $M = (Q, \Sigma, \delta, q_0, F)$ that recognizes $L$ with $Q = \{q_0, q_a, q_b, q_{ab}, q_{ba}, q_{acc}\}$:

State Prefix Condition Tracked Input 'a' Input 'b' Accepting?
q₀ Initial state (ε read) q_a q_b No
q_a Read single 'a' q_acc (saw "aa" ✓) q_ab (saw "ab") No
q_b Read single 'b' q_ba (saw "ba") q_acc (saw "bb" ✓) No
q_ab Prefix is ab⁺ (waiting for 'a') q_acc (saw ab⁺a ✓) q_ab (more b's) No
q_ba Prefix is ba⁺ (waiting for 'b') q_ba (more a's) q_acc (saw ba⁺b ✓) No
q_acc Palindromic prefix detected! Trap accept state q_acc q_acc YES (Final)

Complete 6-state DFA for Language L. The moment a non-trivial palindrome prefix is matched, the automaton transitions to the trap accept state q_acc.

Final Answer

L is regular. It is described by the regular expression $L = (aa + bb + ab^+a + ba^+b)(a+b)^*$ and accepted by the complete 6-state Deterministic Finite Automaton detailed above. ∎

Q1 (b) The Mix of Two Languages
Marks: 4 CO: CO2 Bloom Level: BL3 PO: PO1 PI: 1.1.1
Let Σ = {a, b}. For two non-empty languages L1, L2 over Σ, define:
Mix(L1, L2) = {w1 u w2 v w3 | u ∈ L1, v ∈ L2, w1, w2, w3 ∈ Σ*}.

(i) Give two languages L1, L2 such that Mix(L1, L2) ≠ Mix(L2, L1).
(ii) Show that if L1, L2 are regular, then Mix(L1, L2) is also regular.
(iii) Provide L1, L2 that are not regular, for which Mix(L1, L2) is regular.
Structural Reformulation of Mix

Observe that $w_1, w_2, w_3 \in \Sigma^*$ are arbitrary strings from the universal language $\Sigma^*$. Therefore, the definition of Mix simplifies algebraically to:

$$\text{Mix}(L_1, L_2) = \Sigma^* \cdot L_1 \cdot \Sigma^* \cdot L_2 \cdot \Sigma^*$$

In intuitive terms, $\text{Mix}(L_1, L_2)$ is the set of all words that contain a subword from $L_1$ followed subsequently (with or without intervening symbols) by a subword from $L_2$.

We choose finite (and therefore simple) languages:

$$L_1 = \{a\}, \quad L_2 = \{ab\}$$

Substituting into the simplified form:

  • $\text{Mix}(L_1, L_2) = \Sigma^* \cdot \{a\} \cdot \Sigma^* \cdot \{ab\} \cdot \Sigma^*$ — all words containing an 'a' followed later by the substring "ab".
  • $\text{Mix}(L_2, L_1) = \Sigma^* \cdot \{ab\} \cdot \Sigma^* \cdot \{a\} \cdot \Sigma^*$ — all words containing the substring "ab" followed later by an 'a'.
Witness String: w = aab
  1. Is $aab \in \text{Mix}(L_1, L_2)$? Yes!
    Decomposition: $w_1 = \varepsilon$, $u = a \in L_1$, $w_2 = \varepsilon$, $v = ab \in L_2$, $w_3 = \varepsilon$.
    Concatenation: $\varepsilon \cdot a \cdot \varepsilon \cdot ab \cdot \varepsilon = aab$. Thus $aab \in \text{Mix}(L_1, L_2)$. ✓
  2. Is $aab \in \text{Mix}(L_2, L_1)$? No!
    To belong to $\text{Mix}(L_2, L_1)$, the string must contain an occurrence of $v' \in L_2 = \{ab\}$, followed strictly afterwards by some $u' \in L_1 = \{a\}$.
    The only occurrence of "ab" in the word "aab" is at indices 2–3 (the final two characters).
    The substring following this "ab" is the empty string $\varepsilon$, which contains no 'a'.
    Therefore, no subsequent 'a' exists to match $L_1$. Hence $aab \notin \text{Mix}(L_2, L_1)$. ✗
Final Answer

Choosing $L_1 = \{a\}$ and $L_2 = \{ab\}$, the string $w = \text{aab}$ satisfies $w \in \text{Mix}(L_1, L_2)$ but $w \notin \text{Mix}(L_2, L_1)$. Hence, Mix is not commutative: $\text{Mix}(L_1, L_2) \ne \text{Mix}(L_2, L_1)$.

Formal Closure Proof

We are given that $L_1$ and $L_2$ are regular languages over the alphabet $\Sigma = \{a, b\}$.

  1. Regularity of the alphabet closure: The universal language $\Sigma^* = (a + b)^*$ is recognized by a trivial 1-state DFA, hence $\Sigma^*$ is regular.
  2. Closure under Concatenation: A fundamental theorem of formal language theory states that the class of regular languages is closed under the operation of concatenation. That is, if $A$ and $B$ are regular languages, their concatenation $A \cdot B = \{xy \mid x \in A, y \in B\}$ is also regular.
  3. Inductive Extension: By induction, any finite concatenation of $k$ regular languages $A_1 \cdot A_2 \cdots A_k$ is regular.
  4. Application to Mix: $$\text{Mix}(L_1, L_2) = \Sigma^* \cdot L_1 \cdot \Sigma^* \cdot L_2 \cdot \Sigma^*$$ This is the concatenation of exactly five languages: $A_1 = \Sigma^*$, $A_2 = L_1$, $A_3 = \Sigma^*$, $A_4 = L_2$, and $A_5 = \Sigma^*$.
  5. Since each of the five components is regular, their product $\text{Mix}(L_1, L_2)$ is regular. ∎
NFA Construction (Constructive Verification)

Let $M_1 = (Q_1, \Sigma, \delta_1, q_{01}, F_1)$ and $M_2 = (Q_2, \Sigma, \delta_2, q_{02}, F_2)$ be NFAs recognizing $L_1$ and $L_2$. We construct an NFA $M_{mix}$ for $\text{Mix}(L_1, L_2)$:

  • Create state $s_0$ with self-loops on $a, b$ ($\Sigma^*$), and an $\varepsilon$-transition from $s_0 \to q_{01}$.
  • From every state in $F_1$, add an $\varepsilon$-transition to an intermediate state $s_{mid}$.
  • State $s_{mid}$ has self-loops on $a, b$ ($\Sigma^*$), and an $\varepsilon$-transition to $q_{02}$.
  • From every state in $F_2$, add an $\varepsilon$-transition to final state $s_f$.
  • State $s_f$ has self-loops on $a, b$ ($\Sigma^*$) and is the sole accepting state of $M_{mix}$.

Since an NFA exists that accepts $\text{Mix}(L_1, L_2)$, the language is regular.

Final Answer

Mix(L₁, L₂) is regular because it is the five-fold concatenation of regular languages $\Sigma^* \cdot L_1 \cdot \Sigma^* \cdot L_2 \cdot \Sigma^*$, and regular languages are closed under concatenation. ∎

We construct two genuinely non-regular languages whose Mix collapses into a simple regular language.

Construction: Adding ε to a Classical Non-Regular Language

Define:

$$L_1 = L_2 = \{\varepsilon\} \cup \{a^n b^n : n \ge 1\}$$
Step 1: Rigorous Proof that L₁ and L₂ are NOT Regular

Suppose, for contradiction, that $L_1$ is regular.

  • The singleton set $\{\varepsilon\}$ is finite, hence regular.
  • The class of regular languages is closed under set difference.
  • Therefore, $L_1 \setminus \{\varepsilon\} = \{a^n b^n : n \ge 1\}$ must be regular.
  • However, $\{a^n b^n : n \ge 1\}$ is the classical non-regular language (provable by the Pumping Lemma or Myhill–Nerode theorem). This contradiction proves $L_1$ and $L_2$ are strictly non-regular.
Step 2: Proof that Mix(L₁, L₂) is Regular

Because $\varepsilon \in L_1$ and $\varepsilon \in L_2$, we choose $u = \varepsilon \in L_1$ and $v = \varepsilon \in L_2$.

For any arbitrary string $w \in \Sigma^*$, we can decompose it as:

$$w_1 = w, \quad u = \varepsilon, \quad w_2 = \varepsilon, \quad v = \varepsilon, \quad w_3 = \varepsilon$$

Evaluating the combination:

$$w_1 \cdot u \cdot w_2 \cdot v \cdot w_3 = w \cdot \varepsilon \cdot \varepsilon \cdot \varepsilon \cdot \varepsilon = w$$

Since this holds for every $w \in \Sigma^*$, we have $\Sigma^* \subseteq \text{Mix}(L_1, L_2)$. Furthermore, since $\text{Mix}(L_1, L_2) \subseteq \Sigma^*$ by definition, we obtain:

$$\text{Mix}(L_1, L_2) = \Sigma^* = (a + b)^*$$

The universal language $\Sigma^*$ is regular (accepted by a 1-state DFA).

Final Answer

Take $L_1 = L_2 = \{\varepsilon\} \cup \{a^n b^n : n \ge 1\}$. Both languages are non-regular (by closure under difference with finite sets), yet $\text{Mix}(L_1, L_2) = \Sigma^*$, which is universally regular.

Q1 (c) Algebraic Laws of Regular Expressions
Marks: 4 CO: CO1 Bloom Level: BL3 PO: PO1 PI: 1.1.1
Discuss in brief about the algebraic laws of regular expressions.

Regular expressions over an alphabet $\Sigma$ form an algebraic structure known as a Kleene Algebra. In this system, union ($+$) acts analogously to addition, concatenation acts analogously to multiplication, and the Kleene star ($*$) acts as an unary closure operator.

The Complete Axiomatic Laws of Regular Expressions
Law Category Formal Identity Algebraic Meaning / Interpretation
Commutativity of Union $R + S = S + R$ Order of language alternatives does not affect language membership.
Associativity of Union $(R + S) + T = R + (S + T)$ Grouping of unions is irrelevant.
Associativity of Concat. $(RS)T = R(ST)$ Sequential concatenation groups unambiguously.
Idempotence of Union $R + R = R$ Set union with itself adds no new strings (unlike 1+1=2).
Identity for Union $R + \emptyset = \emptyset + R = R$ Empty language $\emptyset$ is the additive identity.
Identity for Concat. $R\varepsilon = \varepsilon R = R$ Empty string $\varepsilon$ is the multiplicative identity.
Annihilator for Concat. $R\emptyset = \emptyset R = \emptyset$ Concatenating with empty language yields the empty language.
Left Distributivity $R(S + T) = RS + RT$ Concatenation distributes over union from the left.
Right Distributivity $(S + T)R = SR + TR$ Concatenation distributes over union from the right.
Kleene Star Unfolding $R^* = \varepsilon + RR^* = \varepsilon + R^*R$ $R^*$ decomposes into zero copies ($\varepsilon$) or at least one copy.
Star Idempotence $(R^*)^* = R^*, \quad R^*R^* = R^*$ Repeated closure yields no additional strings.
Star Base Cases $\varepsilon^* = \varepsilon, \quad \emptyset^* = \varepsilon$ Zero-length repetitions of empty set produce the empty string.
Sum under Star $(R + S)^* = (R^*S^*)^* = (R^* + S^*)^*$ Interleaved repetitions of $R$ and $S$.
Where Regular Expression Algebra Differs from Ordinary Algebra
Property Ordinary Real Algebra ($x, y$) Regular Expression Algebra ($R, S$)
Multiplication Commutativity $xy = yx$ (Commutative) $RS \ne SR$ in general (e.g., $ab \ne ba$)
Additive Idempotence $x + x = 2x$ $R + R = R$ (Idempotent)
Inverse Operations Subtraction & Division exist No subtraction or division in standard REs
Cancellation Law If $xy = xz$ and $x \ne 0 \implies y = z$ Fails: $a^*(a^*) = a^*(\varepsilon + a)$ but $a^* \ne \varepsilon+a$

We use the algebraic laws to prove this foundational equivalence:

  1. By Kleene star sum expansion: $(R + S)^* = (R^* S)^* R^*$.
  2. Let $R = a$ and $S = b$. Substituting gives: $$(a + b)^* = (a^* b)^* a^*$$
  3. Alternatively, by factoring out leading $a^*$: every string in $(a+b)^*$ consists of zero or more $b$'s separated and flanked by runs of $a$'s ($a^*$). Each occurrence of $b$ carries a trailing run of $a^*$, preceded by an initial run $a^*$: $$(a + b)^* = a^*(b a^*)^*$$
  4. Equating both proves $(a^* b)^* a^* = a^*(b a^*)^* = (a + b)^*$. ∎
Final Answer

Regular expressions form a Kleene algebra characterized by idempotent, commutative union, non-commutative associative concatenation that distributes over union, identities $\emptyset$ and $\varepsilon$, and the star unfolding identity $R^* = \varepsilon + RR^*$.

Q1 (d) Myhill–Nerode Theorem, With a Worked Example
Marks: 4 CO: CO2 Bloom Level: BL3 PO: PO1 PI: 1.1.1
Explain the Myhill–Nerode Theorem by taking a suitable example.
Formal Definition of the Indistinguishability Relation ≡L

Let $L \subseteq \Sigma^*$ be any language over an alphabet $\Sigma$. We define an equivalence relation $\equiv_L$ on $\Sigma^*$, called the Myhill–Nerode indistinguishability relation, as follows:

$$x \equiv_L y \iff \forall z \in \Sigma^*, \quad (xz \in L \iff yz \in L)$$

Two strings $x$ and $y$ are equivalent ($\equiv_L$) if no future suffix $z$ can distinguish between them with respect to membership in $L$. If there exists even one suffix $z \in \Sigma^*$ such that $xz \in L$ and $yz \notin L$ (or vice versa), then $z$ is called a distinguishing extension, and $x \not\equiv_L y$.

Theorem Statement (The Three Equivalent Conditions)

The Myhill–Nerode Theorem states that the following three statements are strictly equivalent:

  1. The language $L$ is regular.
  2. The equivalence relation $\equiv_L$ has a finite number of equivalence classes (finite index).
  3. The minimum number of states in any Deterministic Finite Automaton (DFA) accepting $L$ is precisely equal to the number of equivalence classes of $\equiv_L$. Furthermore, this minimal DFA is unique up to isomorphism.
Worked Example: L = {w ∈ {0, 1}* : w ends in "01"}

Let $\Sigma = \{0, 1\}$. Every string in $\Sigma^*$ falls into exactly one of three distinguishable situations based on its suffix:

Class Representative Situation / Meaning Verified Sample Strings
C₀ ε Does not end in '0' and does not end in '01' (start, or last bit is 1 not preceded by 0) ε, 1, 11, 111, 011
C₁ 0 Ends with a lone '0' — an active candidate start of "01" 0, 10, 00, 110, 010
C₂ 01 Successfully ends in the target pattern "01" (Accepting Class) 01, 101, 1101, 001

We prove that all three classes are pairwise distinct by exhibiting a distinguishing suffix $z$ for every pair:

Pair Tested Distinguishing Suffix (z) First String Extended (xz) Second String Extended (yz) Conclusion
C₀ (ε) vs C₁ (0) z = "1" $\varepsilon \cdot 1 = 1 \notin L$ $0 \cdot 1 = 01 \in L$ Distinguishable! ($\varepsilon \not\equiv_L 0$)
C₀ (ε) vs C₂ (01) z = ε $\varepsilon \cdot \varepsilon = \varepsilon \notin L$ $01 \cdot \varepsilon = 01 \in L$ Distinguishable! ($\varepsilon \not\equiv_L 01$)
C₁ (0) vs C₂ (01) z = "1" $0 \cdot 1 = 01 \in L$ $01 \cdot 1 = 011 \notin L$ Distinguishable! ($0 \not\equiv_L 01$)

Since all pairs are distinguishable, there must be at least 3 equivalence classes.

Closure Under Extension & Minimal DFA Construction

We verify that the 3 classes are closed under the transition function $\delta(C, b) = [w \cdot b]$:

$$\begin{aligned} \delta(C_0, 0) &= C_1, & \delta(C_0, 1) &= C_0 \\ \delta(C_1, 0) &= C_1, & \delta(C_1, 1) &= C_2 \\ \delta(C_2, 0) &= C_1, & \delta(C_2, 1) &= C_0 \end{aligned}$$

Minimal 3-state DFA obtained directly from the 3 Myhill-Nerode equivalence classes.

Proving Non-Regularity with Myhill–Nerode: To prove a language like $L_{nr} = \{0^n 1^n : n \ge 0\}$ is NOT regular, one produces an infinite family of pairwise distinguishable strings $S = \{0^k : k \ge 0\}$. For any $j \ne k$, choose $z = 1^k$. Then $0^k z = 0^k 1^k \in L_{nr}$, but $0^j z = 0^j 1^k \notin L_{nr}$. Hence all strings in $S$ belong to distinct equivalence classes $\implies$ index is infinite $\implies L_{nr}$ is not regular.
Final Answer

The relation $\equiv_L$ partitions $\{0,1\}^*$ into exactly 3 equivalence classes ($C_0, C_1, C_2$). Because the index is finite (3), by the Myhill–Nerode theorem, L is regular, and its unique minimal DFA requires exactly 3 states with $C_2$ as the sole accepting state.

Q2 (a) Writing Regular Expressions for Prescribed Languages
Marks: 3 CO: CO1 Bloom Level: BL3 PO: PO1 PI: 1.1.1
Write regular expressions for the following languages over Σ = {a, b}:
(i) L = {a2n b2m : n ≥ 0, m ≥ 0}
(ii) All strings containing not more than three a's
(iii) All strings which do not contain the substring "ba"
Step-by-Step Derivation
  1. Decomposition of $a^{2n}$ ($n \ge 0$): $a^{2n} = (a^2)^n = (aa)^n$. For $n \ge 0$, this represents any non-negative integer number of pairs of $a$'s: $$(aa)^* = \{\varepsilon, aa, aaaa, aaaaaa, \dots\}$$
  2. Decomposition of $b^{2m}$ ($m \ge 0$): Similarly, $b^{2m} = (bb)^m$, representing any even count of $b$'s: $$(bb)^* = \{\varepsilon, bb, bbbb, bbbbbb, \dots\}$$
  3. Concatenation: All $a$'s strictly precede all $b$'s, with independent counts $n$ and $m$. Concatenating the two expressions:
    $$R = (aa)^*(bb)^*$$
  4. Edge case verification:
    • $n=0, m=0 \implies a^0 b^0 = \varepsilon$ (Accepted by $(aa)^*(bb)^*$ via $\varepsilon \cdot \varepsilon = \varepsilon$) ✓
    • $n=1, m=0 \implies a^2 b^0 = aa$ ✓
    • $n=0, m=1 \implies a^0 b^2 = bb$ ✓
    • $n=1, m=1 \implies a^2 b^2 = aabb$ ✓
    • Odd counts like $a, b, aaa, aab, abb$ are correctly rejected.
Answer (i)

$(aa)^*(bb)^*$

Step-by-Step Derivation

"Not more than three $a$'s" means the total number of $a$'s, denoted $N_a(w)$, can be $0, 1, 2,$ or $3$. The count of $b$'s is completely unrestricted, meaning arbitrary runs of $b^*$ can appear before, between, and after every $a$.

Q2 (b) Arden's Theorem: Formal Statement, Rigorous Proof & Worked DFA
Marks: 3 CO: CO1 Bloom Level: BL3 PO: PO1 PI: 1.1.1
State Arden's theorem. Take a DFA of your choice and find its corresponding regular expression using Arden's theorem.
Formal Statement of Arden's Theorem

Let $P$ and $Q$ be two regular expressions over an alphabet $\Sigma$. If $\varepsilon \notin P$ (i.e., $P$ does not contain the null string $\varepsilon$), then the equation:

$$X = Q + XP$$

has a unique solution given by:

$$X = QP^*$$

Note: In symmetric left-linear form, if $X = Q + PX$ with $\varepsilon \notin P$, the unique solution is $X = P^*Q$.

Part 1: Proof of Existence (Verification that $X = QP^*$ is a solution):

Substitute $X = QP^*$ into the right-hand side of $X = Q + XP$:

$$\text{RHS} = Q + (QP^*)P = Q(\varepsilon + P^*P) = QP^* = X = \text{LHS}$$

By the Kleene star unfolding law, $\varepsilon + P^*P = P^*$. Hence $X = QP^*$ is indeed a valid solution.

Part 2: Proof of Uniqueness (when $\varepsilon \notin P$):

Repeatedly substitute $X = Q + XP$ into itself:

$$\begin{aligned} X &= Q + (Q + XP)P = Q + QP + XP^2 \\ &= Q + QP + (Q + XP)P^2 = Q + QP + QP^2 + XP^3 \\ &\;\;\vdots \\ &= Q(\varepsilon + P + P^2 + \dots + P^k) + XP^{k+1} \end{aligned}$$

Because $\varepsilon \notin P$, every string in $P$ has length at least 1 ($|w| \ge 1$ for all $w \in P$). Consequently, every string in $P^{k+1}$ has length at least $k+1$.

Now consider any string $w$ of length $n$ ($|w| = n$). If we choose $k = n$, then every string in $XP^{n+1}$ must have length $\ge n+1 > |w|$. Therefore, $w$ cannot belong to $XP^{n+1}$. It follows that:

$$w \in X \iff w \in Q(\varepsilon + P + P^2 + \dots + P^n) \subseteq QP^*$$

Since this holds for every string $w \in \Sigma^*$, $X = QP^*$ is the only possible solution. ∎

Q2 (c) Closure Properties of Regular Languages
Marks: 3 CO: CO1 Bloom Level: BL2/3 PO: PO1 PI: 1.1.1
Discuss in brief about the closure properties of regular languages.

A class of languages is said to be closed under an operation if applying that operation to languages within the class always produces a language that also belongs to the class. Regular languages possess remarkably robust closure properties.

Master Table of Closure Operations
Operation Mathematical Notation Formal Constructive Proof Mechanism

Intersection $L_1 \cap L_2$ Product DFA construction with states $Q_1 \times Q_2$ and accepting states $F = F_1 \times F_2$.
Complement $\bar{L} = \Sigma^* \setminus L$ Invert accepting states of a complete DFA: $F' = Q \setminus F$. (Note: Requires a deterministic DFA, fails on NFA).

Reversal $L^R = \{w^R : w \in L\}$ Reverse the direction of every transition arc in an NFA, swap the roles of start state and accepting states.

Decision Properties (Companion Exam Note)

Closely coupled with closure properties are the decision properties of regular languages, all of which are decidable in finite time:

  • Emptiness ($L = \emptyset$): Decidable by testing if any accepting state is reachable from the start state using BFS/DFS.
  • Finiteness ($|L| < \infty$): Decidable by checking for cycles in the state graph along paths from start to an accepting state.
  • Equivalence ($L_1 = L_2$): Decidable by constructing the symmetric difference $(L_1 \cap \bar{L}_2) \cup (\bar{L}_1 \cap L_2)$ and testing for emptiness.
Final Answer

Regular languages form a Boolean algebra (closed under $\cup$, $\cap$, complement, and set difference) that is additionally closed under concatenation, Kleene star, reversal, and homomorphisms. These guarantees enable complex automata and compilers to be assembled modularly.

Q3 (b) Moore Machine vs Mealy Machine: Definitions, Conversion & Sequence Detector

Formal 6-Tuple Definitions

Both Moore and Mealy machines are finite automata with output capabilities, formally defined as 6-tuples:

$$M = (Q, \Sigma, \Delta, \delta, \lambda, q_0)$$

where $Q$ is a finite set of states, $\Sigma$ is the input alphabet, $\Delta$ is the output alphabet, $\delta: Q \times \Sigma \to Q$ is the state transition function, and $q_0$ is the initial state. The sole mathematical difference lies in the output function $\lambda$:

  • Moore Machine: Output is purely a function of the current state: $$\lambda: Q \to \Delta$$
  • Mealy Machine: Output depends on both the current state and the current input symbol: $$\lambda: Q \times \Sigma \to \Delta$$

Output Placement Placed inside the state node: $(q / z)$ Placed on the transition edge: $a / z$
Output Length For input of length $n$, output length is n + 1 (initial state emits output before reading input). For input of length $n$, output length is n.
Hardware Response Time One clock cycle delayed (must transition to and latch into the state). Immediate; changes asynchronously when input changes.
State Complexity Requires more states (needs distinct states for different output values). More compact; requires fewer states.

Q3 (c) Pumping Lemma: Proving {wwᴿ} is Non-Regular
Marks: 3 CO: CO2 Bloom Level: BL2/3 PO: PO1 PI: 1.1.1
Using the pumping lemma, show that L = {wwR : w ∈ (a+b)*} is not regular.
Formal Statement of the Pumping Lemma for Regular Languages

If $L$ is a regular language, then there exists a constant integer $p \ge 1$ (called the pumping length), dependent only on $L$, such that every string $s \in L$ with $|s| \ge p$ can be partitioned into three substrings $s = xyz$ satisfying three conditions:

  1. $|y| \ge 1$   (the pumped substring $y$ is non-empty)
  2. $|xy| \le p$   (the loop $y$ occurs within the first $p$ symbols)
  3. $\forall i \ge 0, \quad x y^i z \in L$   (the string remains in $L$ for all repetitions of $y$, including pumping down $i=0$)
Step-by-Step Proof by Contradiction
  1. Assumption: Assume, for the sake of contradiction, that $L = \{ww^R : w \in (a+b)^*\}$ is regular.
  2. Pumping Length: Let $p$ be the pumping length guaranteed by the pumping lemma.
  3. Choice of String s: We choose a string $s \in L$ strategically such that its symmetry is locked across the boundary of length $p$.
    Let $w = a^p b$. Then $w^R = b a^p$.
    $$s = w \cdot w^R = a^p b b a^p$$
    Notice that:
    • $s$ has the form $u u^R$ with $u = a^p b$, so $s \in L$. ✓
    • $|s| = |a^p b b a^p| = 2p + 2 \ge p$. Thus the pumping lemma must apply to $s$. ✓
  4. Applying the Pumping Lemma Constraints: According to the lemma, $s = xyz$ with $|xy| \le p$ and $|y| \ge 1$.
    The first $p$ characters of $s$ consist entirely of the initial block of $a$'s ($a^p$).
    Because $|xy| \le p$, both $x$ and $y$ must consist solely of $a$'s, and $y$ cannot contain any $b$'s.
    Therefore, we can write:
    $$x = a^j, \quad y = a^k, \quad z = a^{p - j - k} b b a^p$$
    where $j \ge 0$, $k \ge 1$, and $j + k \le p$.
  5. Pumping Down (i = 0): The pumping lemma asserts that $x y^0 z = xz \in L$.
    Let us compute $xz$:
    $$xz = a^j \cdot a^{p - j - k} b b a^p = a^{p - k} b b a^p$$
  6. Analyzing the Resulting String: Since $k \ge 1$, we have $p - k < p$.
    The string $xz$ has $(p-k)$ leading $a$'s before the central $bb$, but it has $p$ trailing $a$'s after the central $bb$.
    For any word to belong to $L = \{ww^R\}$, its first character must equal its last character, its second must equal its second-to-last, and in general, the number of $a$'s preceding the central $bb$ must equal the number of $a$'s following it.
    Here, $(p - k) \ne p$, so $xz$ cannot be partitioned into two identical halves reversed:
    $$xz = a^{p-k} b b a^p \notin L$$
  7. Contradiction: This directly contradicts the third condition of the Pumping Lemma ($xy^0 z \in L$).
Crucial Pitfall to Avoid: Why couldn't we choose $w = a^p$, giving $s = a^{2p}$? Because $s = a^{2p}$ is pumpable! If $y = aa$ ($k=2$), pumping up or down produces $a^{2p \pm 2}$, which is an even number of $a$'s and remains in $L$. To successfully break the lemma, the chosen string must lock down the alphabet symbols with a fixed delimiter like $b$, preventing the loop from rebalancing both halves.
Final Answer

Our assumption that $L$ is regular leads to an impossible contradiction ($a^{p-k}bba^p \in L$ with $k \ge 1$). Therefore, by the Pumping Lemma, $L = \{ww^R : w \in (a+b)^*\}$ is NOT regular. ∎

Q3 (d) Applications & Theoretical Limitations of Finite Automata
Marks: 3 CO: CO2 Bloom Level: BL2/3 PO: PO1 PI: 1.1.1
Discuss in brief about the applications and limitations of finite automata.
Engineering & Computational Applications
  1. Compiler Lexical Analysis (Scanners): Compilers (such as Lex, Flex, and GCC) utilize DFAs to scan input source code and partition characters into syntactic tokens (keywords, identifiers, numeric constants, operators). Because token patterns are regular, DFAs process source code in optimal $O(n)$ linear time.
  2. Pattern Matching & Regular Expression Engines: Software search tools (such as grep, sed, and text editors) convert regular expressions into NFAs using Thompson's construction and simulate them as DFAs to detect text occurrences without backtracking.
  3. Network Protocols & Distributed Systems: Communication standards (e.g., the TCP/IP state machine: LISTEN $\to$ SYN\_SENT $\to$ ESTABLISHED $\to$ FIN\_WAIT $\to$ CLOSED) are explicitly designed and verified as finite state machines to ensure no illegal state transitions or deadlocks occur.
  4. Digital Sequential Circuit Design: Hardware controllers in microprocessors (ALU controllers, cache coherence protocols like MESI, vending machines, traffic lights, and elevator controllers) are implemented as synchronous Moore or Mealy circuits using flip-flops and logic gates.
  5. Bioinformatics: Genetic search algorithms model DNA/RNA sequences (alphabets $\Sigma = \{A, C, G, T\}$) as finite automata to detect motif sites, gene promoter regions, and protein signatures.
Theoretical Limitations
$$\text{Finite Automata possess only } O(1) \text{ finite memory --- they cannot count without bound.}$$
  • Inability to Perform Unbounded Counting: A finite automaton with $k$ states can only remember information up to $k$ configurations. It cannot recognize languages requiring comparison of unbounded quantities, such as $L = \{a^n b^n : n \ge 0\}$.
  • Inability to Verify Arbitrary Nesting: Finite automata cannot validate balanced parentheses or nested block syntax (e.g., ((...)) or HTML/XML tag matching). Such hierarchical structures require a stack data structure, found in Pushdown Automata (Context-Free Languages).
  • Inability to Recognize Global Symmetries: Automata cannot decide palindrome languages $L = \{w w^R\}$ or duplication languages $L = \{w w\}$ because the length of $w$ is unbounded and cannot be stored in fixed states.

Final Answer

Finite automata are the ideal mathematical model when decision logic requires only bounded, fixed memory (compilers, protocols, regex engines). Once a computational problem requires unbounded counting, nested hierarchical matching, or arbitrary scratchpad manipulation, more powerful models (Pushdown Automata or Turing Machines) are fundamentally required.

The Two Crucial Traps to Watch For in Exam Scoring
Trap 1 (Q1 a iii): When asked "Suppose $ax \notin L$, what can you say about $x$?", do NOT write the general complement $\{\varepsilon, a, b\} \cup ab^+ \cup ba^+$. The initial letter $a$ is already supplied, which strictly constrains $x \in b^*$ (meaning $x$ contains zero occurrences of 'a').
Trap 2 (Q2 d): The question specifies a DFA with three states. All four candidate languages are regular, but option (d) ("no 101 substring") requires a minimal DFA with 4 states (progress $\varepsilon, 1, 10,$ and trap $101$). It is the only option that cannot be recognized by a 3-state DFA.
